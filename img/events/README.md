# 活動主視覺橫幅圖

放社群日 / 活動頁最上方的橫幅圖（例如官方社群日宣傳圖）。

## 用法
1. 把圖片存到這個資料夾，建議命名：`年-月-寶可夢英文.jpg`
   例：`2026-09-gible.jpg`
2. 在對應活動頁的 `CD_EVENT` 裡設定路徑（事件頁在 events/<slug>/，所以用 `../../`）：
   ```js
   "bannerImg": "../../img/events/2026-09-gible.jpg",
   ```

## 建議
- 尺寸：寬約 1200–1920px 即可，用 **JPG**（照片類 JPG 比 PNG 小很多）。
- 用「檔案 + 路徑」比在 HTML 裡內嵌 base64 好：頁面較輕、圖片可重複使用。
